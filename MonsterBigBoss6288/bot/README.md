# بوت الث

بوت Messenger يعتمد على `@dongdev/fca-unofficial` بالإصدار `4.0.3`. في
Railway/الإنتاج تُحمّل الجلسة من متغير `APPSTATE_JSON`، وتُحفظ نسخة مؤقتة خاصة
خارجة عن المستودع ومطابقة لبصمة البذرة؛ لا يحتاج إلى Volume. إعادة الدخول عبر
البريد الإلكتروني وكلمة المرور معطلة، ويظل `APPSTATE_PATH` بديلاً محلياً صريحاً
للتطوير فقط. كما أن التحديث الذاتي للحزمة معطل للحفاظ على الإصدار المثبت.

## التشغيل

من مجلد المشروع:

```bash
pnpm --filter @workspace/alth-bot run start
```

أو باستخدام السكربتات المختصرة:

```bash
pnpm run bot:start
pnpm run bot:check
```

يعلن `package.json` أن `index.js` هو ملف التشغيل، وتستدعيه سكربتات `start` و`dev`؛
ويستورد `index.js` الوحدة `main.js` لمعالجة الرسائل والأحداث، لذلك `main.js` جزء نشط
من مسار التشغيل وليس ملفًا قديمًا.

## إعداد الجلسة والإنتاج

- في واجهة Railway، افتح المشروع ثم خدمة البوت ثم **Variables**، وأضف
  `APPSTATE_JSON` بوصفه متغيراً سرياً يحتوي مصفوفة JSON للجلسة. لا تسجل القيمة
  أو تطبعها. يتطلب تعديل الجلسة لاحقاً تغيير هذا المتغير ثم إعادة نشر الخدمة.
- مسارا تحديث الجلسة عبر HTTP يردان بـ`409 Conflict` في Railway/الإنتاج، لأن
  ملفاً محلياً في بيئة مؤقتة ليس مخزناً دائماً.
- للتطوير المحلي فقط، اضبط `APPSTATE_PATH` على ملف JSON محلي خارج المستودع؛ لا
  يُستخدم هذا المسار في Railway/الإنتاج. يشغّل أمر `dev` البوت مع
  `NODE_ENV=development`. إذا عُيّن `APPSTATE_JSON` محلياً،
  تكون له الأولوية ولا تُحفظ تحديثاته إلى ملف.

إعداد مصادقة لوحة التحكم مستقل، ويستخدم متغيرات البيئة التالية دون وضع قيمها
في المستودع: `DASHBOARD_PASSWORD` و`DASHBOARD_SESSION_SECRET` و
`DASHBOARD_ORIGIN`. في الإنتاج، اضبط `APPSTATE_JSON` أيضًا كما هو موضح أعلاه.

## ملفات التشغيل الأخرى

- `admins-config.json`: كائن JSON يحتوي `admins` كمصفوفة من المعرّفات الرقمية
  الموجبة كسلاسل نصية؛ لا تضع المعرّفات كأرقام JSON ولا ترفع الملف إلى Git.
- `commands-config.json`: تفعيل وتعطيل الأوامر.
- `bot-state.json`: حالة التشغيل التي تقرؤها لوحة التحكم.
- `Commands/`: الأوامر التي يتم تحميلها تلقائيًا عند تسجيل الدخول.

الأوامر الإدارية الحالية تشمل:

- `ويس` و`ويس ايقاف`: تشغيل وإيقاف الجرائد.
- `هويه <الكنية>` أو `هوية <الكنية>`: ضبط كنيات الأعضاء بفاصل عشوائي 3-5 ثوانٍ، ثم الحفاظ عليها 24 ساعة بفحص كل 10 ثوانٍ.
- `قروب <اسم المجموعة>`: تغيير اسم المجموعة بعد انتظار عشوائي 5-10 ثوانٍ، ثم الحفاظ عليه 24 ساعة بفحص كل 10 ثوانٍ.
- `إيقاف الاسم` أو `ايقاف الاسم`: إيقاف عمليات تغيير الأسماء والكنيات وحماياتها ومؤقتاتها في المحادثة الحالية فقط، بما فيها عملية `كاتش` الجارية.

إذا كان `admins-config.json` مفقودًا أو تعذرت قراءته أو كان JSON أو هيكله أو أحد
المعرّفات غير صالح، تُحمّل قائمة مشرفين فارغة ولا يحصل أي مستخدم على صلاحيات
إدارية. لا يوجد معرّف مشرف افتراضي.

## ملاحظات

- تعتمد الجلسة على مصفوفة `appstate` الحالية وليس على Meta Graph API.
- يمكن تغيير مسار `yt-dlp` عبر المتغير الاختياري `YTDL_PATH`.

## توافق FCA 4.0.3

- تهيئ الحزمة حالة MQTT الداخلية عند تسجيل الدخول: تضبط `firstListen` إلى `true`، وتغذي `lastSeqId` من قيمة `irisSeqID` المستخرجة، ثم تربط `api.listenMqtt` بهذه الحالة. لذلك لا يستخدم التطبيق واجهة `api.ctx` الخاصة بالمكتبة القديمة؛ اختيار معرّف التسلسل الأولي وإعادة مزامنته مسؤولية الحزمة.
- لا توثق أنواع `FcaOptions` أو README خيار `autoMarkDelivery`، ولا يقبله مُطبّق الخيارات. المصدر يعرض `markAsDelivered` كدالة صريحة، لكن المراجعة الساكنة لم تجد استدعاءً تلقائياً لها من مستمع MQTT. لا يكفي ذلك لإثبات سلوك إقرارات التسليم على اتصال حي؛ أبقِ نشر الإنتاج محظوراً إلى أن يُحسم السلوك المطلوب ويُتحقق منه بتفويض منفصل.
